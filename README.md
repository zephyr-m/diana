# Diana

Личный голосовой клиент Codex. Pipecat/WebRTC → WeSpeaker → Whisper → Codex →
локальный Piper «Ирина». Microsoft Edge «Светлана» доступна через `--tts edge`.
Без аккаунтов приложения, облачного бэкенда и собственной модели распознавания.

## Запуск

```sh
nix-shell --run 'uv run --no-sync python -m diana.owner --mode chat --tts piper --host 127.0.0.1 --port 7863 -t webrtc'
```

- **http://127.0.0.1:7863/** — личный пульт: разговор, микрофон, этапы, задержки, причины решений.
- **http://127.0.0.1:7863/client/** — исходный диагностический клиент Pipecat.

Нажать «Подключить», разрешить микрофон, сказать фразу и сделать паузу.
Одновременно подключать только одну страницу. Клавиатура работает после подключения;
нажатие «Стоп» отменяет ответ и очищает очередь озвучки. Проверка голоса к вводу
с клавиатуры не применяется — это явно обозначено в карточке реплики.

Контекст сохраняется в отдельном диалоге Codex, ID — `.local/conversation-id`.
История на экране ограничена текущей вкладкой, до 100 трассировок и 200 сообщений;
после перезагрузки экран пустой, но Codex продолжает помнить контекст.
`--conversation-state .local/other-thread` создаёт независимый диалог.

## Что показывает пульт

- Реальный уровень PCM микрофона, результат WeSpeaker и предварительный порог.
- Очередь, проверку владельца, Whisper, ожидание Codex, синтез и передачу аудио.
- Причины отказа: короткая речь, несовпадение голоса, переполненная очередь, ошибка.
- Минимальное сходство среди проверенных окон — **не вероятность**.
- Временную шкалу, ID диалога и JSON-экспорт реплики с текстом и ответом.
- Выбор микрофона и динамиков (последнее зависит от поддержки браузером).

Все длительности измеряются монотонными часами сервера. «До отправки звука» —
от последнего состояния речи VAD (для клавиатуры — от приёма текста) до первого
аудио в выходном тракте. Это не точное время до слышимого звука: браузер, WebRTC
и динамики добавляют задержку. «Первое аудио» включает синтез первого предложения,
загрузку и декодирование. Пауза включает поведение VAD; пропущенные этапы показаны
прочерком, а не фиктивными нулями. Причины — факты программы, не рассуждения модели.

## Озвучка и данные

`--tts edge` (опционально): `ru-RU-SvetlanaNeural` через готовый
[edge-tts](https://github.com/rany2/edge-tts). API-ключ и браузер Edge не нужны;
текст ответа передаётся Microsoft. При ошибке или тайм-ауте 15 секунд используется
Piper; повторная попытка Edge возможна через минуту. Пульт сообщает о переключении.

`--tts piper` (по умолчанию): локальная Ирина, `ru_RU-irina-medium`. Онлайн-сервис озвучки не вызывается.
Аудио обрабатывается в памяти, декодируется PyAV и передаётся в браузер по WebRTC.
В текущей реализации предложение сначала синтезируется целиком, затем воспроизводится.

Микрофон, проверка голоса и Whisper работают локально. В Codex уходит распознанный
или набранный текст; авторизация и история остаются в установленном Codex.
Сырые записи не сохраняются. `.local/`, `.venv/`, модели и профиль исключены из Git.
Экспорт диагностики содержит текст — файл создаётся только по нажатию кнопки.

## Ограничения

Проверка владельца **временно выключена по умолчанию** в chat/transcribe: любая
речь проходит в Whisper. Переключатель «Проверять мой голос» находится в настройках
пульта, действует со следующей обрабатываемой реплики и сбрасывается при новом
подключении. Профиль не изменяется. VAD и распознавание продолжают работать.
Ниже описаны ограничения проверки, когда переключатель включён.

- Голосовая проверка вероятностная. Порог 0.35 выбран по небольшой начальной выборке:
  владелец 0.493–0.668, чужая запись 0.067–0.132. Смешанные/новые голоса не гарантированно разделяются.
- Для проверки нужна минимум секунда речи. Окна перекрываются, хвост тоже проверяется;
  несовпадение отклоняет всю реплику до Whisper и Codex.
- Пауза 0.8 с после состояния речи VAD завершает реплику. После 20 с обрабатывается
  только начало; обрезка обозначена в трассировке. Очередь ограничена двумя репликами.
- Новая подтверждённая и распознанная фраза прерывает ответ; мгновенное перебивание
  по началу речи ещё не реализовано. Для разговора удобнее наушники.
- Сейчас это разговор. Инструкция запрещает действия, файловая песочница read-only,
  запросы подтверждений клиент отклоняет. Это не изолированный чат без инструментов:
  используются настройки установленного Codex. Выполнение голосовых команд и UI
  подтверждений не подключены. Текущим открытым чатом другого приложения Diana не управляет.
- Сервер предназначен для localhost и единственного владельца, не для публикации в интернет.

## Установка на NixOS

Требуется установленный и авторизованный Codex. Голосовые библиотеки и модели:

```sh
nix-shell --run 'bash scripts/install-voice.sh'
nix-shell --run 'bash scripts/prepare-models.sh'
```

Многоязычный Whisper small, Piper и WeSpeaker ResNet34 ONNX скачиваются в `.local/models`.
WeSpeaker загружается из официального Hugging Face с закреплённой ревизией и SHA256;
проверка TLS включена. Torch/torchaudio — CPU-версии. Whisper — CPU int8, четыре потока.
Синтетическая проба проверяет работу моделей, но не становится профилем владельца.

Пульт использует готовый JS-клиент Pipecat и SmallWebRTC, без фреймворка и CDN:

```sh
npm ci
npm run build
```

После изменения `web/app.js` нужна повторная сборка. `web/dist/` исключён из Git.

### Первый запуск: профиль владельца

```sh
nix-shell --run 'uv run --no-sync python -m diana.owner --mode enroll --host 127.0.0.1 --port 7863 -t webrtc'
```

Открыть `/client/`, нажать Connect, говорить одному до сообщения «Профиль сохранён».
Сохраняются шесть фрагментов по две секунды речи в нормализованный вектор
`.local/owner.json` (права 0600); исходное аудио не записывается. Существующий профиль
не перезаписывается. После регистрации остановить сервер и запустить `--mode chat`.
Диагностические режимы `--mode verify` и `--mode transcribe` доступны на `/client/`.

## Проверки

```sh
nix-shell --run 'uv run --no-sync python -m unittest discover -s tests -v'
nix-shell --run 'uv run --no-sync python scripts/check-transcription.py'
nix-shell --run 'uv run --no-sync python scripts/check-dialogue.py'
```

Последний скрипт делает реальный запрос Codex в отдельном тестовом диалоге,
проверяет восстановление контекста и Piper. Профиль владельца не изменяется.

Браузерная проверка использует искусственный микрофон, отдельный диалог и настоящий
ответ Codex/озвучку. Сначала запустить тестовый сервер в другом терминале:

```sh
nix-shell --run 'uv run --no-sync python -m diana.owner --mode chat --tts edge --conversation-state .local/ui-test-thread --host 127.0.0.1 --port 7864 -t webrtc'
npm run test:ui
```

По умолчанию используется `/run/current-system/sw/bin/google-chrome-stable`;
другой путь задаётся `CHROME_PATH`. Снимки экрана и результаты — `.local/`.
